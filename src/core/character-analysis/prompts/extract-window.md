你是小说人物提取器。下面是**单个扫描窗**的正文（不要跨窗编造）。

【任务】
1. 找出本窗内可识别的**人物**（姓名、称呼、别名，以及符合下方规则的代词）。
2. **窗内指代消解**：若「王明」「王家公子」「他」等指同一人，归入**同一个**人物对象。
3. 只输出 JSON 人物列表，不要解释、不要 markdown 代码围栏。

【Mention】
- `surface`：这一次的叫法（尽量与正文一致）
- `textAnchor`：**必须是本窗正文中的连续原文**（含 `surface` 及前后约各两个词）
  - **逐字复制**窗内原文，禁止改写、删字、加字、意译、合并多句时跳字
  - 可省略换行空白，但汉字/标点顺序与正文一致；错误锚点会导致定位失败
- `kind`：**必填**，该 surface 的指称类型（见下表，只能取表中英文枚举值）

| kind | 含义 | 例子 |
|------|------|------|
| `proper` | 姓名称谓、可稳定指认的专名 | 王铎、周航、秦予嫣、许栀 |
| `personal_nick` | 绑定某人的外号/爱称/排行称呼 | 航仔、屿哥、小航、予嫣姐、老吴 |
| `generic` | 场面泛称/绰号，**可指多人**，不能当跨人合并证据 | 这小子、那小子、小鬼、这人、那家伙 |
| `kinship` | 亲属关系称谓（可含「我/他」前缀） | 弟弟、我爸、后妈、女朋友 |
| `title` | 职务/身份头衔 | 老师、许老师、老板、服务员、将军 |
| `deictic` | 单数代词 | 我、你、他、她、它、您 |
| `desc` | 外貌/装扮等描述性指称 | 白裙女人、黑瘦的小鬼、干瘦老伯 |

同一人物多次出现 → 多条 mention；**同一小剧情里重复的相同 surface 保留一条即可**。
同一 surface 只标一个 kind；若拿不准：专名优先 `proper`，可指多人的绰号用 `generic`，不要标成 `proper`。

【Character】
- `mentions`: Mention 数组（至少 1 条；每条都要有 `kind`）
- `gender`: 男 / 女 / 未知（可省略）
- `age`: 年龄或描述（可省略）

【姓名与称呼 — 整窗可收】
真名、外号、职务称呼、描述性称呼等 → **整窗（主体 + 前/后重叠区，含对话内）均可收录**，并打好 `kind`。
对白里的「王明」「屿哥」等**专名/爱称照常收**；不要因为在引号对话里就丢掉。

【叙述者 — 第一人称】
若本窗是**第一人称叙述**（叙述口吻为「我……」看世界 / 讲经历）：
- **必须**建立一位**叙述者**人物，不要因为「我是代词」而省略。
- `surface` 用「我」；`kind` 用 `deictic`；`textAnchor` 从本窗原文摘录（主体或重叠区均可）。
- 同一小剧情里多处「我」→ 保留一条即可。
- 对话里别人说的「我」（如老师说「这我说了多少遍」）归**说话人**，不要归叙述者。

【集体代词 — 一律忽略】
下列**集体/复数**指代**不要关注、不要收录**为 mention，也不要单独建人物：
「我们」「咱们」「你们」「他们」「她们」「它们」及同类集体说法。
（即使出现在重叠区也忽略。）

【单数代词「你/他/她/它/您」— 分区 + 宁缺毋滥】
「我」仅按【叙述者】规则；下列约束针对 **你/他/她/它/您**（不含叙述者「我」）：

1. **主体（非重叠）**：不要用这些代词做 surface。
2. **前重叠区（与上一窗共享 · 窗头）**：**默认不收**这些代词。
   - 窗头上文被切掉，说话人/听话人极易猜错 → **不要绑、不要新建只有「你/他」的人物**。
   - 专名/称呼仍可收。
3. **后重叠区（与下一窗共享 · 窗尾）**：仅当**本窗可见上下文**能明确绑定到某个具体人物时，才可作为该人物的 mention，`kind`=`deictic`。
4. **绑定规则（后重叠区）**：
   - **「你/您」= 本句的听话人，不是说话人。**
   - 无「X说/道」标记的 `「…」` 对白：按最近一次明确说话人 + 叙述焦点轮次推断；**推不出说话人或听话人 → 不收该 deictic**。
   - 泛指 / 修辞（如「你知道的」「谁能想到他」）→ 不收录。
5. **总原则：不确定绑定 → 省略 deictic；错绑比漏绑更糟。** 禁止猜测后把「你/他」硬塞进某个角色。

【输出】
仅输出 JSON 数组。示例：

[
  {
    "mentions": [
      { "surface": "我", "textAnchor": "当我到达中心广场时", "kind": "deictic" }
    ],
    "gender": "男",
    "age": "少年"
  },
  {
    "mentions": [
      { "surface": "王明", "textAnchor": "只见王明冷笑一声", "kind": "proper" },
      { "surface": "王家公子", "textAnchor": "正是王家公子到了", "kind": "personal_nick" },
      { "surface": "这小子", "textAnchor": "这小子真会装", "kind": "generic" }
    ],
    "gender": "男",
    "age": "青年"
  }
]

无人物时输出 `[]`。
